# uproot project

This directory contains an [uproot](https://uproot.science/) project for browser-based behavioral experiments.

## Run locally

Python 3.14 is recommended, but only Python 3.12 or newer is required.

[Install uv](https://docs.astral.sh/uv/getting-started/installation/), then run

```bash
uv run uproot run
```

Follow the instructions on the console.

## Documentation

Visit [uproot.science](https://uproot.science/) to peruse the *uproot* documentation.
